Methodology

Data science workflow, verification pipeline, and reproducible Pandas computations.

Analysis Pipeline

  1. Load — Read insurance.csv into a Pandas DataFrame using absolute path resolution
  2. Validate — Ensure required columns (smoker, charges) exist and validate data types
  3. Clean — Trim whitespace, lowercase smoker categories, coerce charges to numeric, drop corrupted rows
  4. GroupBy — df.groupby('smoker')['charges'].mean()
  5. Plot — Generate Seaborn barplot with errorbar=('ci', 95), capsize=0.15, and exact value annotations
Python 
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 1. Load dataset
df = pd.read_csv("data/insurance.csv")

# 2. Core Pandas calculation (assigned deliverable)
grouped = df.groupby('smoker')['charges'].mean()
print(grouped)

# 3. Seaborn visualization with 95% CI error whiskers
fig, ax = plt.subplots(figsize=(9.6, 5.4))
sns.barplot(
    data=df,
    x='smoker',
    y='charges',
    order=['no', 'yes'],
    errorbar=('ci', 95),
    capsize=0.15,
    err_kws={'linewidth': 2.2, 'color': '#1C1B19'},
    palette={'no': '#1F6F63', 'yes': '#B5442E'},
    ax=ax,
)
plt.ylabel("Mean Charges (USD)")
plt.xlabel("")
plt.tight_layout()
plt.savefig("outputs/smoker_charges_comparison.png", dpi=300)
plt.show()

Methodological Limitations

  • Observational data — This is a cross-sectional observational dataset. Subjects were not randomly assigned to smoking/non-smoking groups.
  • Correlation ≠ Causation — The difference in charges between smokers and non-smokers does not prove that smoking causes higher charges. Confounders (age, BMI, region) may contribute.
  • Unbalanced groups — Non-smokers (n = 1,064) outnumber smokers (n = 274), which affects statistical power and variance estimates.
  • Single source — Results reflect this specific insurance dataset and should not be used for clinical decision-making.
