Analysis Pipeline

  1. Load — Read insurance.csv into a Pandas DataFrame
  2. Validate — Ensure required columns (smoker, charges) exist
  3. Clean — Normalize smoker values, coerce charges to float, drop invalid rows
  4. GroupBy — df.groupby('smoker')['charges'].mean()
  5. Plot — Generate Seaborn barplot with 95% CI error bars
Python 
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Load dataset
df = pd.read_csv("data/insurance.csv")

# Core analysis
grouped = df.groupby('smoker')['charges'].mean()
print(grouped)

# Visualization
sns.barplot(data=df, x='smoker', y='charges',
            estimator='mean', errorbar=('ci', 95))
plt.title("Average Insurance Charges by Smoking Status")
plt.ylabel("Average Charges ($)")
plt.xlabel("Smoker")
plt.tight_layout()
plt.savefig("outputs/smoker_charges_comparison.png", dpi=300)
plt.show()

Limitations

  • Observational data — This is a cross-sectional observational dataset. Subjects were not randomly assigned to smoking/non-smoking groups.
  • Correlation ≠ Causation — The difference in charges between smokers and non-smokers does not prove that smoking causes higher charges. Confounders (age, BMI, region) may contribute.
  • Unbalanced groups — Non-smokers (n ≈ 1,064) vastly outnumber smokers (n ≈ 274), which affects statistical power and confidence interval widths.
  • Single source — Results may not generalize beyond this particular dataset or insurance market.
